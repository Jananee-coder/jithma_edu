# Jithma Institute – Student Management System

## Project Overview
The Jithma Institute Student Management System is a web-based application developed to manage student and administrative activities at Jithma Institute, Dagonna. The system replaces manual record-keeping with a centralized database-driven solution.

## Key Features
- Student and Guardian Management
- Student Registration and Batch Management
- Attendance Management
- Student Payment Management
- Teacher Management
- Teacher Payment Management
- Class and Hall Allocation Management
- Employee and User Management
- Role-Based Access Control
- Administrative Reports

## Technologies Used
- **Backend:** Java 21, Spring Boot, Spring Security
- **Frontend:** HTML, CSS, JavaScript, Thymeleaf, Bootstrap 5, jQuery
- **Database:** MySQL
- **Tools:** Visual Studio Code, MySQL Workbench, Figma, Visual Paradigm

## User Roles
- Admin
- Manager
- Coordinator
- Receptionist
- Card-Checker

## Purpose
This project was developed as part of my final-year Bachelor of Information Technology (BIT) project. It aims to improve the efficiency of student record management and administrative operations in an educational institute.
